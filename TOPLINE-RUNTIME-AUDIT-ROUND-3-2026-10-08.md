## Fixed
**Invoice status helper called a revoked function.** Migration 068 revoked `update_invoice_status_transaction` from signed-in users and replaced it with `transition_invoice_lifecycle`, but `src/lib/finance.ts` (used by the `useInvoices` hook) still called the old one, which fails with "permission denied for function". The invoices admin page itself already used the canonical function through `finance-operations.ts`; the helper is now aligned so it cannot fail if used. The canonical function validates transitions, requires line items before sending, refuses "paid" while a balance remains, and writes an `invoice_events` row.

## New safeguard
`supabase/tests/browser_rpc_grants.sql` (generated by `scripts/generate-rpc-grant-test.mjs` from the 150 `supabase.rpc()` calls in `src/`): fails if any function the browser calls is missing or not executable by `anon` or `authenticated`. Proven to fail when the revoked invoice function is listed. `verify:sql-runtime-safety` fails if the generated list drifts from the source, so run the generator after adding an RPC call.
